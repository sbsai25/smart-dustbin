# Smart Dustbin: AI Waste Classifier

This project uses Artificial Intelligence to identify different types of trash (**wet waste**, **dry waste** and **e-waste**) for automatic sorting in a smart dustbin.
It was built using Python and a model trained with Google Teachable Machine, which recognizes waste live through a webcam.
The repository contains the trained model files (`converted_keras`) and the Python scripts needed to run it.

To try it out, install the required libraries and run `try.py` (press `q` to quit):

```bash
pip install -r requirements.txt
python try.py
```
